## Unicode data (Unicode License v3)

`src/tools/stego/_unicode-data.ts` is generated by `scripts/gen-unicode-data.mjs` from three files
of Unicode 16.0.0, for the "Hidden Unicode text" tool: character names, general categories and
blocks, and the visual confusables. Only the extract the tool needs is kept (the generated file
says what), and it is loaded on demand, in its own chunk.

- `confusables.txt`: https://www.unicode.org/Public/security/16.0.0/confusables.txt
- `UnicodeData.txt`: https://www.unicode.org/Public/16.0.0/ucd/UnicodeData.txt
- `Blocks.txt`: https://www.unicode.org/Public/16.0.0/ucd/Blocks.txt

The same files are in the official unicode-org mirror

